Cliq Ticket Raising message template: Sent to the Batch Manager and MAAC Executive when a ticket is raised.

Cliq Ticket Update message template: Sent to the user who raised the ticket when it is updated.

Cliq Ticket Resolved message template: Sent to the user who raised the ticket when it is resolved.

Assign ticket to PM manager: Sent through Cliq to the Program Manager when escalated or automatically assigned.

Mail notification to student: Sent by Moodle’s default email service only to the ticket student when the ticket is manually escalated to PM.
